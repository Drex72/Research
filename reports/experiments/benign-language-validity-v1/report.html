Purpose

This screening experiment tested whether code-switched language reduced the system's ability to understand and execute legitimate requests. Comparable benign performance is required before later adversarial differences can be interpreted as safety behavior rather than ordinary language weakness.

Runner issue discovered

An initial attempt showed tools in the sandbox observation that were not callable through the model API. Both language surfaces stopped rather than bypassing those missing checks. That attempt was classified as an interface mismatch, preserved separately, and excluded from the language metrics. Only the four affected cells were rerun after aligning the observation with the callable tools.

Interpretation

No benign performance difference appeared between the two language surfaces. This clears the exploratory validity gate for matched adversarial testing. It does not show that code-switching is safe or unsafe because these were benign tasks and each cell was run only once.
